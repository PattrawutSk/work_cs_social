# Image Text Reader

A lightweight web application for personal and team use that uses OCR to extract and search text from images, helping reduce manual effort and improve data accuracy.

## Features
- Paste, drag and drop, or upload images
- Extract and search text using OCR
- Group and filter recognized references
- Copy formatted data with one click
- Process images locally in the browser

## Usage
Open `index.html` in a browser. Internet access is required to load OCR resources.

## Privacy
Images are processed in browser memory and are not uploaded to an application backend. OCR resources are loaded from external CDNs.
